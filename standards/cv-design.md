# CV Design Standard

Canonical design standard for every resume generated by the career sector
(`ocf:cv-tailor`, skill `cv-tailor`, skill `cv-pdf`). Every generated resume
MUST conform to this standard. The reference template
(`skills/career/cv-pdf/templates/resume.html`) is the mandatory starting
point: agents adapt the CONTENT, never rewrite the CSS from scratch.

The rules below are concrete and testable (MUST statements with measurable
values), not opinions.

## 1. ATS compatibility

1. Semantic headings MUST be used: exactly one `h1` for the candidate name,
   `h2` for standard section titles, and `h3` for sub-entries (job title,
   institution, project name).
2. Section titles MUST follow the standard set — Summary, Experience,
   Education, Skills, Certifications, Projects, Languages — localized to the
   job language. Empty sections MUST be omitted.
3. All text MUST be real, selectable text — NEVER text rendered as an image.
4. The layout MUST be single-column. CSS `columns`/multicol and two-column
   flex/grid layouts are FORBIDDEN (they break ATS parsing order).
5. Complex tables are FORBIDDEN. Key/value lines (contact, dates) MUST be
   plain text lines or simple inline lists, not table cells.
6. Fonts MUST be ATS-safe system fonts: `Helvetica`, `Arial`, `sans-serif`.
   Web fonts (Google Fonts or any remote font) are FORBIDDEN — they may not
   render headless and some ATS cannot parse them.
7. Emoji and decorative characters are FORBIDDEN in content and markup.
   Standard typographic punctuation (`·` middle dot, `—` em dash, bullets
   from plain `ul` lists) is ALLOWED — it parses as regular text.
8. Dates MUST be plain text (e.g. `Jan 2020 — Dec 2023`), never icons or
   calendar images.
9. Text contrast MUST be >= 4.5:1 (WCAG AA) for body text against the
   background.
10. A printed copy MUST be fully readable: no information may require a link
    click or hover to be understood.

## 2. Print

1. Page size MUST be A4: `@page { size: A4; margin: 12mm 15mm; }`. Margins
   MUST be between 12mm and 15mm on every side.
2. The resume MUST be fully legible in black-and-white: no information may be
   conveyed by color alone (e.g. colored status dots). Hierarchy comes from
   weight, size, and spacing — never from color.
3. Backgrounds and images MUST be absent in print. A clean `@media print`
   block MUST exist in the generated HTML that removes any background/image
   and keeps the layout intact.
4. `break-inside: avoid` MUST be applied to sections and entries so they do
   not split awkwardly across pages; `break-after: avoid` MUST be applied to
   `h2` so a section title is never orphaned at the bottom of a page.

## 3. Sober professional style

1. Typography hierarchy MUST be discrete: name > section title > body.
   Recommended print sizes: name 15–17pt bold, section titles 10.5–11pt
   bold/small-caps, body 9.5–10.5pt, line-height 1.4–1.5.
2. Spacing MUST be generous: ~6–10mm between sections, ~3–5mm between
   entries. No cramped blocks.
3. At most ONE accent color is allowed, and it MUST be grayscale-safe (the
   resume must remain fully readable and understandable when printed in
   black-and-white). Default: no accent — emphasis uses the text color.
4. Gradients, shadows, decorative borders, background tints, and emoji are
   FORBIDDEN. A single hairline under section titles is allowed as a
   structural divider.
5. Body text MUST NOT be pure black (`#000`); use a near-black such as
   `#1a1a1a`.

## 4. Length by seniority

1. Junior/Pleno resumes MUST fit on exactly ONE A4 page.
2. Senior/Especialista/Lead resumes MUST fit on AT MOST TWO A4 pages.
3. Three or more pages are FORBIDDEN for any resume.
4. Density MUST NOT exceed ~600–700 words per page.

## 5. Conformity checklist (run before PDF generation)

Before generating the PDF, the cv-tailor agent MUST verify every item:

- [ ] Exactly one `h1` (candidate name) and `h2` section headings present
- [ ] Single-column layout; no `columns`/multicol
- [ ] No `<img>`, no text-as-image, no complex tables
- [ ] Font stack is `Helvetica, Arial, sans-serif`; no Google Fonts/remote fonts
- [ ] No emoji or decorative characters
- [ ] Dates as plain text
- [ ] `@page { size: A4; margin: 12mm 15mm; }` present (margins 12–15mm)
- [ ] `@media print` block present and clean
- [ ] No color-dependent information (legible in black-and-white)
- [ ] No gradients/shadows/decorative borders/background tints
- [ ] Page count: 1 page (Junior/Pleno) or at most 2 (Senior+)
- [ ] Word count <= ~700 words per page

The reference template already satisfies this checklist — adapt the content,
preserve the structure.
